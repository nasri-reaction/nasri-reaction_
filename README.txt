NASRI REACTION ROOM — site gratuit, responsive

OUVRIR LE SITE SUR TON PC
1. Décompresse le fichier ZIP.
2. Ouvre le dossier nasri-reaction-site.
3. Double-clique sur index.html pour voir le site.
4. Pour modifier le code, ouvre le dossier dans VS Code.

PERSONNALISER LES LIENS YOUTUBE
Dans index.html, cherche https://www.youtube.com/ et remplace chaque lien par le lien de la vidéo ou de ta chaîne.
Les miniatures sont des designs graphiques temporaires : tu peux les remplacer par tes propres covers en ajoutant des images dans le dossier et en modifiant les cartes dans index.html.

METTRE LE SITE EN LIGNE GRATUITEMENT AVEC GITHUB PAGES
1. Crée un compte sur https://github.com/ si tu n'en as pas.
2. Crée un nouveau repository public, par exemple nasri-reaction-room.
3. Envoie les fichiers index.html, style.css et script.js à ce repository (pas le dossier ZIP).
4. Dans le repository, ouvre Settings → Pages.
5. Dans Build and deployment, choisis Deploy from a branch, puis main et /(root), puis Save.
6. Attends quelques minutes : GitHub affichera l'adresse gratuite de ton site dans la section Pages.

À SAVOIR
- L'hébergement GitHub Pages est gratuit pour un site statique public.
- Un domaine personnalisé en .tn peut coûter de l'argent; ce n'est pas nécessaire pour commencer.
- Les boutons YouTube sont des liens de démonstration : remplace-les par tes vrais liens avant publication.
